# Cross-context

Cross-context resolves terms whose meaning differs between the contexts in the
[glossary map](../../../GLOSSARY-MAP.md).

## Language

**Governance scope**:
The management group or subscription to which Azure Governance binds a policy
assignment.
_Avoid_: scope

**Runtime scope**:
The set of subscriptions that Azure Retirement Intelligence selects for
evidence collection.
_Avoid_: scope
